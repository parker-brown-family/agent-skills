Briefing · engineering · hardening pass

Briefing, hardened for strangers

The briefing skill shipped this morning with every test passing. This pass asked whether an agent on someone else's machine, reading only the skill, could build a brief and get the reader's comments back, then fixed what stopped it.

Ready to review

One branch, harden/briefing-portable, built on the round-trip fixes already merged. 42 Python tests and the browser check pass. A rebuild bug that stripped every page's wallpaper is fixed; the matching bug in the sibling glass gate is filed.

01 Six Probes

The tests passed because they asked what their authors expected. Each probe here is one scratch file and one command a newcomer could plausibly run. Three passed, or lost work, without a word. Three failed with a Python error in place of the problem.

Probing also turned up a bug outside this skill. The glass gate passes a page with no wallpaper, because the shared stylesheet's own comment matches the pattern it searches for. That gate belongs to fancy-pants-brief, so it is filed as an issue with a reproduction rather than patched here. The finding.

02 The Way Back

The biggest gap was on the return trip. A reader in an ordinary browser keeps their notes in that browser, and the only way out is the copy map button, whose text lands in a chat. resolve read only JSON, so the commonest return could not be placed against the page at all.

It now reads that text as pasted, from a file or from stdin. The text names the page and the first twelve hex digits of its revision, so a comment made on an older version is still flagged. The text also joins each note's lines with spaces, and the result says so.

03 Starting Cold

A newcomer also has to know what will work before trying it. One command now reports, for each part of the skill, whether this machine can run it and why not, and says unknown rather than no when it could not look. Another writes a starting page with every required marker in place and a visible placeholder wherever writing is still owed, and the checker refuses the brief until every placeholder is gone. This page began that way.

Those are doctor, new and check. The new SKILL.md opens on that loop, and refusals maps every refusal to what it means and what to do.

04 A Cold Reader's Run

The last test was a reader with no context. A fresh agent got only the skill's path and four tasks: a Markdown brief, the same brief in HTML with a drawing, a pasted copy map resolved fresh and then stale, and doctor. It finished all four. Its worst finding was one this page had just shown: rebuild a page and its wallpaper is gone.

The rest of its report changed the helper and the docs. Pasted text with Windows line endings, a byte-order mark or a chat quote is now read. Built pages are readable by others again, where they had been saved owner-only. check lists every broken link at once. A scaffolded source names itself, so a rebuild needs no flags, and two refusals now name their next step. The docs gained the copy map's grammar and a way to put your own page through the browser check. One finding stays as it is: an id ending in twelve hex digits can be misread, but only in hand-typed text, and then it lands in review. The full report.
