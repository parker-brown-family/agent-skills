What you scrolled past now comes back

Briefs already timed every passage. Now the agent reads those times back, names what you scrolled past, and the skill says what to do with each one in the next brief.

01 The agent gets a verdict, not a stopwatch

Raw seconds tell an agent nothing. A section of 160 words needs about 42 seconds; 3 seconds on screen means you scrolled past it. So each passage's time is now set against its reading time, and anything under 40% is marked passed. The verdict rides in Copy map with your notes, so one click carries it back.

02 Passed means one of two things, and the agent decides which

You put it this way: what gets scrolled past is either not relevant, or important but it did not get your attention. The skill now makes the writer pick one, every round, and say so in the next brief's Last time strip.

03 The clock only proves the negative

A passage that was on screen long enough may still have gone unread, especially on a big screen where several sit side by side. So the verdicts claim only what time can show. Had time means there was room to read. Unseen is zero seconds while the page was active. Unmeasured means no record exists, which is not zero. A page nobody has read says so, and draws no conclusion.

04 Brevity is a number the agent sees before handing over

The lesson you took from Lavish was brevity. check now prints the estimated reading time and every section over 150 words of prose. It warns and does not refuse, so a long section stays the writer's call, made with the number in view. By that count this page reads in about three minutes and has no long section.

05 Across many briefs, it shows where readers drop off

Give attention a folder of briefs and it tallies what gets passed: by kind of passage (opening, section, figure, entry) and by first, middle or last third. If figures or last sections keep getting passed, that is a change to the skill, not to one page. Today only two of the seven pages in this plan folder have any reading time, so it is too early to read a pattern.

06 Where it stands

This sits on the sibling agent's pull request as one more commit, so the whole feature is still one review. The clock also does less work now: it measures the page once per frame on scroll instead of on every scroll event.

The native Terminal Delight reader builds its own Copy map in Rust, on the sibling's unmerged branch. It still sends raw times without the verdict. Until it changes, brief.py attention on the saved page gives the same answer from either reader.
