Saved Reading

You want each brief to remember how long its sections were on screen. I recommend keeping it as HTML with JavaScript. Terminal Delight can save those times beside your notes; a browser needs a small local server to update the same file.

01 The original file

Terminal Delight already saves notes into the original HTML. A browser review session would get the same ability through a local server limited to the file you opened. The agent can then read that file for both comments and visible time.

02 The visible reader

Terminal Delight currently displays page snapshots. A timer running inside its hidden browser would miss your actual scrolling. It must measure its own visible surface; a browser measures the real page with JavaScript.

Both pause when the document loses focus or a modal covers it. The file keeps times tied to the version you saw. Failed saves stay marked pending. Short views remain clues for the next writer to investigate.

Opening the file directly in a browser still works, but saves stay in browser storage. The local review session enables saving the original. Read the technical design and source evidence.
