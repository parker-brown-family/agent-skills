Program design · brief reading

Active Reading

A brief left still for an hour will count that hour while it stays on screen and active. Switching away pauses the clock. The design uses the reader’s focus and visibility signals, with no mouse or keyboard inactivity cutoff.

01 The clock

A brief’s visible sections and figures each keep their own time. A covering modal pauses the background document. When monitoring resumes after sleep or a stall, the missing interval stays a gap.

02 The saved record

I propose checking visibility each second and saving changed times every five seconds, plus when you switch away. A save failure stays marked pending. Repeated saves cannot add the same time twice.

The verification will include an hour with no input, a page left open all day in the background, and a note saved during a timer update. Types, file changes and test plan.

03 The choice

Use this clock behavior?

Recommend counting all active visible time, checking each second and saving every five seconds. Save behavior.
