# theme-rolodex — the themes brief-wall draws a brief's wallpaper from.
#
# This file is the draw. brief-wall picks a theme from the lines below, evenly, then one of
# that theme's wallpapers. Nothing that is not on a live line here is drawn, so the stock
# Omarchy themes are out simply because they are commented out at the bottom.
#
#   name   source   [path inside the repository]   # note
#
# source is owner/repo on GitHub, any git URL, or "-" for a theme that only exists installed
# on this machine. A theme installed under that name (~/.config/omarchy/themes and the
# like) is used from disk; otherwise brief-wall fetches its colors.toml and ONE wallpaper,
# never the whole repository, into ~/.cache/brief-wall, which it keeps under 300 MB by
# dropping the wallpapers used longest ago (BRIEF_WALL_CACHE_MB changes the cap).
#
# To take a theme out, put a # in front of it. To put one in, add a line or delete the #.
# `brief-wall --list` shows the draw as it stands, and `brief-wall --theme NAME` still
# reaches any theme, on the list or not.
#
# Curated 2026-11-20 from ~490 GitHub repositories (the awesome-omarchy list plus searches
# for Omarchy themes): kept the ones with a colors.toml and wallpapers, a look of their own,
# and art that will sit under glass. Notes are the theme author's own description.
# Stars and wallpaper counts are as of that day.
