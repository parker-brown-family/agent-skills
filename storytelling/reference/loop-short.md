# The loop short

A short whose ending feeds the beginning, so the replay reads as the next
sentence rather than as a repeat. The target is that **the viewer does not
realise they have restarted for two to four seconds** — by the time they notice,
they have watched it twice.

This is not "cut the last frame to match the first". Footage that merely repeats
is a loop the eye catches instantly. The loops that hold align four things at
once: the final frame, the motion across the cut, the audio, and — the one most
people skip — the **story context**. The sentence has to continue.

## The structure

```
SHORT TYPE: NARRATIVE LOOP
TARGET: 25–35 seconds

HOOK          A sentence that sounds complete enough to grab attention,
              and can also grammatically follow the final sentence.
SETUP         The human problem, in five seconds or less.
ESCALATION    Why the obvious solution failed.
TURN          The unexpected insight. This is the thing being paid for.
PAYOFF        The actual result, with a real number where one exists.
LOOP BRIDGE   The last three to eight words, written to lead into the hook.
VISUAL LOOP   Where possible, the final shot matches or motivates the first.
```

## The test

**Read the final card, then immediately read the first card.** If it sounds
intentional, the loop works. If you have to explain why it works, it does not.

That test is brutal and it is the whole quality gate. Run it out loud. A loop
that only works on paper is a loop that fails at speed.

## The five shapes

### 1. Sentence loop

The grammar itself completes on replay. The strongest and the hardest.

> The weirdest thing about coding with AI is that the AI usually isn't the problem.
> I had six agents working on the same project. Every one of them could write code.
> But they kept forgetting why we were building it. So instead of giving them more
> intelligence, we gave them a shared story. **And that's when I realized…**

↺ *"The weirdest thing about coding with AI…"*

### 2. Question → answer → question

The ending hands the question back before the answer has finished landing.

> **Why did my coding agent keep making the same stupid mistake?**
> It wasn't the model. It wasn't the prompt. Every new agent simply woke up with no
> idea what the last agent had learned. So we gave the project memory.
> **Which finally answered the question…**

↺ *"Why did my coding agent keep making the same stupid mistake?"*

### 3. Reveal loop

Open on the artifact, withhold what it is, and let the last line re-present it.

> **This little text file replaced about twenty prompts.**
> [the problem: agents behaving inconsistently] → [SKILL.md]
> **And the entire thing is just…**

↺ *"This little text file replaced about twenty prompts."*

### 4. Causal loop

A contradiction stated flat, then earned, then handed back as a conclusion.

> **I accidentally made my coding agents slower by making them smarter.**
> More context → bigger prompts → more confusion → specialised skills → less
> context → faster agent.
> **Which is how…**

↺ *"I accidentally made my coding agents slower by making them smarter."*

### 5. Visual + verbal loop

Both the edit and the narrative loop. The strongest available format when the
subject is a screen, which for us it usually is.

> [first frame: a terminal with six agent panes]
> **This is what happens when you hire six developers who have amnesia.**
> [agent context loss, coordination] → [the last shot returns to the identical
> terminal layout]
> **So without shared memory…**

↺ *"This is what happens when you hire six developers who have amnesia."*

## Writing one

1. **Write the payoff first**, then the hook, then the bridge between them. A
   loop written front-to-back almost never closes; the bridge is a constraint on
   the hook, not a decoration on the ending.
2. **Keep the hook grammatically open at the front.** "The fastest way to break
   something is…" accepts a preceding clause. "Here's why my agent failed" does
   not — nothing can precede "Here's".
3. **Bridges that work:** *and that's when I realised… / which is how… / which
   finally answered the question… / so without… / and the entire thing is just…*
4. **Bridges that do not:** anything that names the subject again. Repetition is
   what makes a loop visible.
5. **Cut the recap.** A loop short has no summary; the hook is the summary and it
   is about to play again.

## For agent-development shorts

Sentence loop plus technical reveal is the default 30-second form. The subject
is a screen doing something wrong, which means the visual loop is usually free:
the session returns to the state it started in, because that is exactly the
failure being shown.

The payoff should be a real number off the transcript — *36 times, fifteen
hours* — never a characterisation. The number is what makes the turn land, and
it is the one thing a viewer repeats to someone else.
